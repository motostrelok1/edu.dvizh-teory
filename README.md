# ПДД — обучающее приложение для курсантов

Интерактивный учебник Правил дорожного движения Российской Федерации,
собранный из официального PDF (Постановление Совета Министров — Правительства РФ
от 23.10.1993 N 1090, с изменениями на 16 июля 2025 г., действует с 01.09.2025).

Каждый раздел оформлен как **лекция по единой схеме**: мотивация (зачем это изучать) →
текст урока (пункты ПДД целиком + авторские разборы ключевых пунктов) → примеры
и антипримеры → интерактивный тест.

## Возможности

- **30 разделов-лекций**: 26 разделов Правил (Общие положения, Обязанности
  водителей/пешеходов/пассажиров, Спецсигналы, Светофор, Скорость, Обгон,
  Перекрёстки, Перевозка людей и грузов, Нормы времени и т.д.) и 4 приложения
  (Дорожные знаки, Дорожная разметка, Основные положения по допуску ТС,
  Перечень неисправностей).
- **139 вопросов** в интерактивных тестах (выбор ответа с объяснением).
- **392 иллюстрации на своих местах** — знаки, разметка, схемы и опознавательные
  знаки вставлены там, где они стоят в оригинале.
- **Живые ссылки на знаки и разметку** — упоминания вида «знак 2.4» или «разметка 1.1»
  в текстах автоматически становятся ссылками: открывают карточку и позволяют
  перейти в справочник и обратно.
- **Прогресс обучения** — отметка «Изучено» по разделу, индикатор в шапке;
  данные в localStorage браузера.
- **Поиск** по всему тексту Правил с фрагментами-контекстом.
- **Адаптивная вёрстка** — desktop и мобильные устройства.

## Технологии

React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui. Данные — статический JSON
(`public/sections.json`) и изображения (`public/img/`). Контент лекций собирается
скриптами в `tools/` (Python) из исходных текстов разделов.

## Структура проекта

```
pdd-trainer/
├── public/
│   ├── sections.json        # контент: 30 разделов, лекционные блоки
│   └── img/                 # ~380 уникальных иллюстраций (PNG)
├── src/
│   ├── App.tsx              # каркас: шапка, поиск, sidebar, контент
│   ├── components/
│   │   ├── Sidebar.tsx      # меню разделов с прогрессом
│   │   ├── LectureView.tsx  # рендер лекции (мотивация, темы, цитаты, термины,
│   │   │                    #   примеры, тест, проход p/h2/img)
│   │   ├── SectionView.tsx  # обёртка раздела
│   │   ├── Refs.tsx         # модалка знака/разметки со ссылками перехода
│   │   ├── RefText.tsx      # авто-ссылки «знак N.N» / «разметка N.N» в тексте
│   │   └── SearchBox.tsx    # поиск по тексту
│   ├── lib/refs.ts          # индекс знаков и разметки, парсер ссылок
│   └── hooks/usePdd.ts      # загрузка данных, прогресс, навигация
└── tools/                   # генераторы контента (Python, идемпотентные)
    ├── make_s1_lecture.py   # лекция раздела 1 + хелперы блоков
    ├── make_s2_lecture.py   # лекция раздела 2
    ├── lecture_lib.py       # авторазметка пунктов -> цитаты
    ├── lecture_data.py      # авторский контент: мотивации, разборы, тесты
    ├── make_all_lectures.py # сборка всех лекций в sections.json
    └── sections_originals_backup.json  # исходные тексты разделов
```

## Запуск

```bash
npm install
npm run dev      # разработка (порт 3000)
npm run build    # прод-сборка в dist/
```

## Деплой

Статический сайт: `npm run build`, содержимое `dist/` отдаётся nginx.
GitHub Actions (`.github/workflows/deploy.yml`) — сборка и выгрузка на VDS по SSH
при каждом пушу в `main`. Сайт: https://edu.dvizh-school.ru

См. также: [STATUS.md](STATUS.md) — текущее состояние, [RUN.md](RUN.md) — подробности запуска.
